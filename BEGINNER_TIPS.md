# Beginner hints & tips

Advanced New Tab helps people new to Obsidian find their notes and learn built-in features a little at a time. A standalone new tab displays one of these 36 tips at random. Consecutive new tabs avoid repeating the same tip during a session; the tip stays fixed while that tab is open.

Enable the relevant tools in **Settings → Core plugins**. Keyboard shortcuts below are defaults: Ctrl on Windows/Linux and Cmd on macOS. Check **Settings → Hotkeys** if you have changed them. Core Search examples apply to Obsidian’s Search sidebar. Each item links to its official documentation.

1. **Command palette** — Enable Command palette in Settings → Core plugins. Press Ctrl/Cmd+P, type part of a command name, and press Enter to run it. [Official help](https://obsidian.md/help/plugins/command-palette).

2. **Commands with /** — Enable Slash commands in Settings → Core plugins. In a note, type / at the start of a line or after a space, then search for a command. Esc closes the menu. [Official help](https://obsidian.md/help/plugins/slash-commands).

3. **Pin frequent commands** — In Command palette settings, add commands to Pinned commands. Your frequent actions appear at the top when you open the palette. [Official help](https://obsidian.md/help/plugins/command-palette).

4. **Choose your own hotkeys** — Settings → Hotkeys lets you search for a command and assign a shortcut. If a suggested shortcut does not work, check your current bindings there. [Official help](https://obsidian.md/help/hotkeys).

5. **Start with core plugins** — Settings → Core plugins contains built-in tools such as Daily notes, Templates, and Canvas. Turn on the ones you need as you learn. [Official help](https://obsidian.md/help/plugins).

6. **Find a note quickly** — With Quick switcher enabled, press Ctrl/Cmd+O and type a note name or alias. Use the arrow keys and Enter to open a result. [Official help](https://obsidian.md/help/plugins/quick-switcher).

7. **Connect your notes** — Type `[[` in a note and choose another note to link to it. A link to a note that does not exist yet can become a new note when you open it. [Official help](https://obsidian.md/help/links).

8. **Link to a specific heading** — After selecting a note in a `[[link]]`, type # to choose a heading. `[[Note#Heading]]` takes you directly to that section. [Official help](https://obsidian.md/help/links).

9. **Show another note inline** — `![[Note]]` displays another note inside the current one. `![[image.png]]` displays a vault image, and `![[Note#Heading]]` embeds one section. [Official help](https://obsidian.md/help/Linking+notes+and+files/Embed+files).

10. **See who links to this note** — Enable Backlinks and open its sidebar tab to find notes that link to the current note. Unlinked mentions can reveal names you have not connected yet. [Official help](https://obsidian.md/help/plugins/backlinks).

11. **Give a note another name** — Add nicknames or abbreviations to a note’s aliases property. These names appear in link suggestions, so you can refer to one note in several ways. [Official help](https://obsidian.md/help/aliases).

12. **Organize with headings** — Start a line with # and a space for a heading, or ## and a space for a subheading. Headings make long notes easier to scan. [Official help](https://obsidian.md/help/syntax).

13. **Emphasize key points** — Use `**text**` for bold, `*text*` for italics, and `==text==` for highlighting. Try them in Live Preview to see the formatting as you write. [Official help](https://obsidian.md/help/syntax).

14. **Make a checklist** — Start a line with `- [ ]` followed by your task. In Reading view, click the checkbox to mark it complete; `- [x]` stores a completed task. [Official help](https://obsidian.md/help/syntax).

15. **Build a simple list** — Start lines with - and a space for bullets, or 1. and a space for numbering. Tab indents a list item; Shift+Tab moves it back. [Official help](https://obsidian.md/help/syntax).

16. **Add a visible tip box** — Run Insert callout from the command palette to add a box. Change `[!note]` to `[!tip]` or `[!warning]` to suit the content. [Official help](https://obsidian.md/help/callouts).

17. **Group notes with tags** — Add `#meeting` or another tag to a note, then click it to find related notes. Enable Tags view to browse tags in the sidebar. [Official help](https://obsidian.md/help/tags).

18. **Use nested tags** — A slash creates a tag hierarchy, such as `#work/meeting` and `#work/idea`. Tags cannot contain spaces; use hyphens to separate words. [Official help](https://obsidian.md/help/tags).

19. **Search inside your notes** — With Search enabled, press Ctrl/Cmd+Shift+F to search note contents across the vault. Put a phrase in quotes, such as "project plan", for an exact match. [Official help](https://obsidian.md/help/plugins/search).

20. **Narrow core Search results** — In the core Search sidebar, use `file:meeting` for filenames, `path:Projects` for folders, or `tag:#work` for tags. These operators belong to core Search. [Official help](https://obsidian.md/help/plugins/search).

21. **Find unfinished tasks** — Enter `task-todo:` in the core Search sidebar to find unchecked tasks. Add a word, such as `task-todo:call`, to narrow the results. [Official help](https://obsidian.md/help/plugins/search).

22. **Keep useful notes close** — Enable Bookmarks, then right-click a file in File explorer and bookmark it. Use bookmark groups to arrange frequent notes by topic. [Official help](https://obsidian.md/help/plugins/bookmarks).

23. **Save a useful search** — In the core Search sidebar, run a search, open the three-dot menu under the search field, and choose Bookmark to reuse that search later. [Official help](https://obsidian.md/help/plugins/bookmarks).

24. **Start a daily log** — Enable Daily notes and run Open today’s daily note from the command palette. Set a folder and template in Daily notes settings for a consistent journal. [Official help](https://obsidian.md/help/plugins/daily-notes).

25. **Reuse a note structure** — Enable Templates and choose a template folder in its settings. In an existing note, run Templates: Insert template to insert a saved structure at the cursor. [Official help](https://obsidian.md/help/plugins/templates).

26. **Fill template values automatically** — In core Templates, `{{title}}`, `{{date}}`, and `{{time}}` become the current note title, date, and time. `{{date:YYYY-MM-DD}}` specifies a date format. [Official help](https://obsidian.md/help/plugins/templates).

27. **Navigate a long note** — Enable Outline to list the current note’s headings in the sidebar. Click a heading to jump there, or drag it to rearrange sections. [Official help](https://obsidian.md/help/plugins/outline).

28. **Preview before opening** — With Page preview enabled, hold Ctrl/Cmd while hovering over an internal link in the editor. Its settings control which places require the modifier key. [Official help](https://obsidian.md/help/plugins/page-preview).

29. **Explore nearby connections** — Enable Graph view and run Open local graph to see notes connected to the current note. Increase its depth to explore more distant connections. [Official help](https://obsidian.md/help/plugins/graph).

30. **Arrange ideas visually** — Enable Canvas to place notes, images, and text cards on a large board. Connect cards with lines and group related ideas to plan a project. [Official help](https://obsidian.md/help/plugins/canvas).

31. **Add structured information** — Run Add file property to add details such as status or a date. Use the same property names across notes to make filtering and sorting easier. [Official help](https://obsidian.md/help/properties).

32. **Turn notes into a table** — Enable Bases to show notes and their properties in a table. Filter and sort a reading list or project list while keeping data in your local notes. [Official help](https://obsidian.md/help/bases).

33. **Split a long note** — Enable Note composer, select text in the editor, and run Extract current selection. Move one topic into its own note and keep a link to it. [Official help](https://obsidian.md/help/plugins/note-composer).

34. **Recover an earlier version** — Enable File recovery to keep local snapshots. In its settings, open Snapshots → View to find an earlier version. Keep a separate backup of your vault too. [Official help](https://obsidian.md/help/plugins/file-recovery).

35. **Save a useful layout** — Enable Workspaces and run Manage workspace layouts to save your open tabs and sidebar layout. Create separate layouts for writing and reviewing. [Official help](https://obsidian.md/help/plugins/workspaces).

36. **Switch between writing and reading** — Press Ctrl/Cmd+E to switch between Editing and Reading view. Live Preview formats text while you edit; Source mode shows the Markdown syntax. [Official help](https://obsidian.md/help/edit-and-read).

Toggle **Show beginner hints & tips** in the plugin’s settings to hide or show this area. Tips are bundled locally; opening a help link visits the official Obsidian website.
